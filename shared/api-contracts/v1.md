# Smart Resort 360 - API Contract v1

This document defines the frozen API contracts for the Phase 3 backend.
All responses follow a standard envelope:
```json
{
  "success": true,
  "data": {},
  "meta": {}
}
```

## GET /api/v1/dashboard
**Query:** `?role=gm`
**Role Requirements:** gm, revenue_manager, facilities_lead
**Description:** Returns dashboard stats.
**Success Response:**
```json
{
  "success": true,
  "data": {
    "occupancy": 0.85,
    "goppar": 120,
    "burnout": 0.4,
    "service_score": 4.5,
    "alerts": []
  },
  "meta": { "source": "demo", "is_fallback": true, "timestamp": "ISO_DATE" }
}
```

## POST /api/v1/simulate
**Request Body:**
```json
{
  "occupancy": 0.95,
  "weather": "Stormy",
  "inflation": 0.25
}
```
**Constraints:** occupancy between 0.60 and 1.00.
**Success Response:**
```json
{
  "success": true,
  "data": {
    "goppar": 95,
    "hk_delay_hours": 2,
    "burnout_risk": 0.7,
    "wait_time": 15
  },
  "meta": { "source": "demo", "is_fallback": true }
}
```
